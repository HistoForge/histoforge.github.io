# Using HistoForge

Start with one representative image. Choose a module, check its result on a small region, then
apply the workflow to more regions or whole slides.

For analysis, complete [Setup](../getting-started/index.md) first. HistoForge should show
**Connected**. If your slides are stored in Amazon S3, see the optional
[cloud image guide](cloud-images.md); AWS access is separate from the analysis backend.
