# How to cite HistoForge

When reporting work that uses HistoForge, cite the software, QuPath, and the models or scripts
used in your analysis.

## HistoForge

Include this software citation in your references:

> HistoForge contributors. (2026). *HistoForge* [Computer software].
> <https://github.com/histoforge>

In your Methods, report the HistoForge version used. If that release has a DOI, use it in the
citation above in place of the project link.

## QuPath

Report the QuPath version and follow the official
[How to cite QuPath](https://qupath.readthedocs.io/en/stable/docs/intro/citing.html)
guidance for its recommended paper.

## Models and modules

A HistoForge module can include models and scripts from other projects. Check the module's
README on Hugging Face and the original model or software documentation for citation guidance.
Crediting HistoForge does not replace those references.
