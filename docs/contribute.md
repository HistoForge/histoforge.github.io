# Share a module or dataset

You can [publish a HistoForge module](training/publish.md) directly from QuPath to a Hugging Face
repository you control. Public repositories with the `histoforge` tag appear in the
[modules library](https://huggingface.co/models?other=histoforge). You do not need to contact the
HistoForge team to publish.

To combine models or add processing and measurements, start with
[Module authoring](module-authoring/index.md). To adapt a model to annotated images, follow
[Training](training/index.md).

To discuss contributing a dataset or model, email
[histoforge.contact@gmail.com](mailto:histoforge.contact@gmail.com). Briefly describe the tissue,
stain and analysis task, and what you have—images, annotations, model weights or code. Include a
public link and license information if available.

Start with a description or public link. Do not email confidential or patient-identifiable data.
