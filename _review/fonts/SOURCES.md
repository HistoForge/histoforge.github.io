# Review typeface sources

These Latin WOFF2 files were downloaded without modification from Google Fonts on
20 September 2026. Only the local review build includes them. The selector loads a font only
when it is used; no external font service is contacted by the page.

Each accompanying `*-OFL.txt` preserves its copyright notice and SIL Open Font License 1.1.
Notices were retrieved from `google/fonts` commit
`e44c4b011a820c2cbe2fd2cfa8052037d7edb571`, under `ofl/<family>/OFL.txt`.
Line endings and trailing whitespace in the text notices were normalized; their wording was
not changed. No font binaries were edited, renamed internally or regenerated.

Variable families cover weights 400–650. Static families use separate files: Lato at 400 and
700; Martel Sans at 400 and 600; Barlow, Hind and IBM Plex Serif at 400, 500 and 600. Their CSS
declares those actual weights; the browser selects the closest available weight where needed.
All files are upright. The landing stylesheet disables synthetic weights and styles.

Source Serif 4, Newsreader, Literata, Noto Serif and IBM Plex Serif use serif headings and
Source Sans 3 body text. All other trials use one family throughout the landing page.

[`_static/fonts/`](../../_static/fonts/SOURCES.md), not duplicated here. Review controls use
the selected body typeface too.
