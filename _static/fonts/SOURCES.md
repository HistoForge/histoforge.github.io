# Landing typeface source

The landing page uses the self-hosted Latin subset of Source Sans 3, under the SIL Open
Font License 1.1. Its copyright notice and full license are in `sourcesans3-OFL.txt`.
The documentation theme is unchanged; the browser does not contact a font CDN.

| File | Source |
|---|---|
| `sourcesans3-latin.woff2` | [Google Fonts](https://fonts.gstatic.com/s/sourcesans3/v19/nwpStKy2OAdR1K-IwhWudF-R3w8aZejf5Hc.woff2) |

Downloaded on 20 September 2026 without modification. The notice was retrieved from
`google/fonts` commit `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`, at
`ofl/sourcesans3/OFL.txt`. Line endings and trailing whitespace in the notice were normalized;
its wording was not changed. The font binary was not edited, renamed internally or regenerated.
Both files were moved from the review assets when Source Sans 3 became the landing default.

The file is upright and variable; its CSS declares weights 400–650. The landing page uses
400, 500 and 600, with synthetic weights and styles disabled.
